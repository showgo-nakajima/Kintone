# 3.Kintoneアプリ フィールド設計

## カード管理アプリ
1. フィールド名	フィールドコード	型
2. カードID	card_id	文字列(1行)
3. カード名	card_name	文字列(1行)
4. カード画像	card_image	添付ファイル
5. 属性	attribute	ドロップダウン
6. 種族	race	ドロップダウン
  * 炎属性（FIRE）
  * 水属性（WATER）
  * 地属性（EARTH）
  * 風属性（WIND）
  * 光属性（LIGHT）
  * 闇属性（DARK）
  * 神属性（DIVINE）
7. レベル	level	数値
8. 攻撃力	atk	数値
9. 守備力	def	数値
10. レアリティ	rarity	ドロップダウン
11. 所持枚数	owned_count	数値
12. お気に入り	favorite	チェックボックス
13. メモ	memo	複数行文字列
